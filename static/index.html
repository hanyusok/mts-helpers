모바일 간편 접수 이용 방법

1

접수 화면 접속

원내 비치된 QR코드를 스마트폰으로 스캔하거나 위 '모바일 간편 접수' 버튼을 누릅니다.

2

환자 정보 입력

진료받으실 소아 환자의 성명과 생년월일을 입력하고 확인을 진행합니다.

3

접수 완료

원내 EMR 차트와 연동되어 진료 대기열에 안전하게 등록됩니다.

4

실시간 대기 확인

스마트폰 또는 대기실 전광판에서 내 순번을 확인 후 진료실로 입장합니다.
